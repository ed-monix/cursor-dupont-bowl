# Sample GM files

Three worked examples of a `general-manager.md`, written against the current
`teams/_template/general-manager.md` (Public bio + Gut & Superstitions + Media
Diet & Gullibility included). They are **samples**, not live teams — nothing in
here is picked up by the weekly runs. Copy one into `teams/<slug>/` and edit, or
use them as a quality bar for the real Phase 5 celebrity GMs.

Each one is built to the template's core rule: **every personality trait cashes
out in a mechanical bias** — a thing the GM overpays for, refuses to do, or
triggers on — so ten of these will diverge instead of all collapsing into
"start the highest projection."

| File | Archetype | The tell |
|---|---|---|
| `the-quant.md` | Analytics absolutist | Trusts the model, sneers at the tabloid |
| `the-loyalist.md` | Ride-or-die | Never cuts his guys; spite-starts them |
| `the-gambler.md` | Chaos merchant | FAAB bombs; believes every rumor |
